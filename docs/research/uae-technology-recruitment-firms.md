# Genuine UAE technology recruitment firms

**Retrieved:** 31 August 2026
**Question:** Which recruitment firms have current public evidence that they genuinely recruit technology professionals in the UAE?

## Qualification rule

This is an open-ended qualified set, not a top-N list. A firm is included when current public evidence supports all three conditions:

1. A UAE office or active UAE recruitment operation.
2. An explicit technology recruitment practice covering fields such as software, data, AI, cloud, cyber security, infrastructure, product, ERP or digital transformation.
3. Operating evidence such as current UAE technology mandates, a named recruiter team, published placements or an active technology jobs service.

Scale, longevity and international reach are useful attributes. They do not determine whether a genuine specialist belongs in the set. Company figures below are self-reported unless the source says otherwise.

## Search evidence

Ordinary web search and the configured Brave Search API returned useful candidates within seconds, mixed with promotional lists and unsupported claims. Each candidate therefore needed a separate evidence check.

The configured Serper API returned `400 Not enough credits`. A direct Codex Search comparison took about seven minutes and used 171,361 tokens. It produced useful candidates but duplicated its final output. This supports using fast search for discovery, followed by evidence checks for each firm.

## Strength ranking

- Technology specialisation: 30 points
- UAE operating depth: 25 points
- Current technology mandates or hiring activity: 20 points
- Named recruiter or team evidence: 15 points
- Scale and track record: 10 points

## Recruiter-level follow-up

The next stage should search every qualified firm for named recruiters rather than selecting an arbitrary number of firms. A recruiter qualifies when current evidence supports the firm relationship, a technology specialism and UAE market coverage. Official team pages, current firm-authored role posts and public professional profiles can all provide that evidence.

Firm size and reputation should remain visible attributes. They can help users sort or filter the results, but they must not remove genuine specialist firms from the search pool.

## LinkedIn retrieval and engagement boundary

Public web search can discover official LinkedIn company pages and public recruiter profile URLs. A logged-in LinkedIn browser session is useful for human verification and contact, but it should not be attached to an automated scraper or third-party MCP server.

LinkedIn's [open developer permissions](https://learn.microsoft.com/en-us/linkedin/shared/authentication/getting-access) cover the authenticated member's own profile and email plus social sharing. They do not provide general recruiter search or messaging. The broader [Profile API](https://learn.microsoft.com/en-us/linkedin/shared/integrations/people/profile-api) is restricted to approved developers and says applications may not store profile data for members other than the authenticated member. [Recruiter System Connect](https://learn.microsoft.com/en-us/linkedin/talent/recruiter-system-connect/recruiter-system-connect) is a restricted partner integration for ATS and LinkedIn Recruiter synchronisation, not an open people-search API.

LinkedIn also states that third-party software and browser extensions must not scrape or automate activity on its site. Automated access, connection requests or messages can result in account restrictions. An MCP server does not change those permissions merely because it exposes the activity as tools.

The safe immediate workflow is:

1. Use public search and firm-owned pages to resolve each firm's official LinkedIn page and discover recruiter profile URLs.
2. Rank recruiter matches using current firm, UAE coverage, relevant specialism and evidence freshness.
3. Open the selected LinkedIn URL in the user's normal browser for human verification.
4. Let Job Radar prepare a connection note or message from retained evidence and the user's profile.
5. Require the user to copy or paste the draft and press Connect or Send inside LinkedIn.

This route keeps credentials and cookies outside Job Radar. It also preserves an adapter boundary: public research supplies Evidence, while a separate engagement launcher opens a user-confirmed destination. LinkedIn remains an infrastructure-specific implementation detail rather than part of the core Recruiter or Prospect model.
